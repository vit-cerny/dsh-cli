## 3. Defects found and fixed

1. **A failed `resume` corrupted stderr with a raw escape sequence.**
   `restoreTerminal()` wrote `ESC[?25h` from a process `exit` hook even when the
   UI never started. `node src/main.js resume does-not-exist 2>&1` printed a
   stray `[?25h]` line after the real error. Fixed by tracking whether the UI
   actually took the terminal and only restoring then.
2. **Invalid `--timeout` leaked an internal error name.** The message read
   `dsh-cli: UsageError: invalid --timeout value: bogus`. `parseTimeout` threw a
   plain `Error` tagged to look like a `UsageError`, so the formatter took the
   generic branch. It now throws the real `UsageError` and names the accepted
   formats: `invalid --timeout value: bogus (use 30, 90s, 5m or 1h)`.
3. **Slash-command output never reached the screen.** `submit()` dispatched a
   `/command`, the command wrote into the transcript sink, and the method
   returned without repainting. The output sat in memory until some unrelated
   event forced a frame. In the terminal this looked like `/help` and every
   toolbar tab doing nothing. Fixed by repainting after dispatch; covered by the
   new `Enter on the active tab renders that command output` GUI case.
4. **The top toolbar was missing.** The full-screen rewrite deleted the
   `Toolbar` class and stopped importing it, so the first frame had no
   session/project/plugins/skills/model bar. Restored as a header row in
   `FullScreenView`, with Tab cycling the tabs, Enter opening the active one,
   and the active tab marked with brackets rather than colour alone.

All four are covered by tests: 198 unit tests and 9 real-terminal GUI tests,
0 failures.

## 4. Defects found and not fixed (they need a product decision)

1. **The status bar always shows a cost, even with no usage.** Before any turn it
   reads `$0.0000` rather than omitting the figure. That is honest for a priced
   route with zero calls, but it reads as a fake precision on a route with no
   catalog entry (the same route shows `cost unknown` in `dsh-cli usage`). Worth
   deciding: hide cost until `calls > 0`.
2. **The Rust port is a stub.** `rust/` contains `Cargo.toml` and a `main.rs` that
   prints `dsh-rust`; no dependencies are vendored, and `cargo` cannot reach
   crates.io on this machine through Windows schannel
   (`SEC_E_NO_CREDENTIALS`). The working CLI is still Node. Nothing in the README
   claims otherwise, so this is an unfinished direction rather than a false
   claim, but it does not satisfy "made in rust".
3. **No real streaming in the UI.** Assistant text appears when the message
   completes, not token by token, so a long answer shows `workingâ€¦` with a still
   transcript. This matches the previous behaviour but is below what the
   [CC]-style reference does.
4. **The toolbar tabs are navigation, not live state.** Each tab runs the matching
   slash command, so it shows current data on open; it does not display a live
   count (for example how many sessions exist) in the bar itself. That would need
   the inventory loaded at startup, which costs a few hundred milliseconds.

## 5. Notes on the test harness

- The GUI suite previously hung forever after passing, because node-pty keeps a
  ConPTY handle alive. The runner now passes `--test-force-exit` and the harness
  exposes `quit()`; the full suite finishes in ~29 s.
- The harness could not distinguish "sandbox forbids named pipes" from "the app
  is broken": it threw `EPERM` on `\\.\pipe\conpty-...`. A skip reason based on a
  probe spawn would make that honest. **Not yet applied** â€” the concurrent edit
  to `pty-harness.js` landed first and I did not want to overwrite it.
- `tests/gui/capture.mjs` and `tests/gui/probe-ctrld.mjs` were added during this
  review as diagnostics. They are useful for debugging a failing frame; keep or
  delete them deliberately.

## 6. Verdict

The CLI is functional and its core paths are tested for real, including inside a
pseudo-terminal. A live turn, piped mode, every subcommand, and the error paths
all behave. Four defects were found and fixed, including one that made every
slash command's output invisible; 198 unit tests and 9 real-terminal GUI tests
pass.

The [CC]-style top toolbar now exists and works: Tab moves the highlight, Enter
opens the active tab, and the active tab is marked in text as well as colour.
It is a navigation bar over live commands rather than a live dashboard, and
answers still appear per message rather than per token.

The Rust port remains an empty shell: this is a Node CLI today.
